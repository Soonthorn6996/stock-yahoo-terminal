## How to Start the Project

```bash
# Backend (Terminal 1)
cd apps/api
source .venv/bin/activate
uvicorn app.main:app --reload --port 8000

# Frontend (Terminal 2)
cd apps/web
pnpm dev
```

API docs at `http://localhost:8000/docs` (Swagger UI auto-generated by FastAPI).

## Coding Conventions

### Backend (FastAPI)
- **Routers** are thin — validate with Pydantic, call a service, return response. No business logic in routers.
- **Services** own all logic: `yahoo_service.py`, `ai_service.py`.
- **Auth** — all protected routes use `Depends(get_current_user)` dependency.
- **Errors** — raise `HTTPException` with appropriate status codes.
- **Async** — use `async def` for all route handlers and service calls (yfinance calls wrap in `asyncio.to_thread`).

### Frontend (Next.js)
- **Server Components** for initial data fetch where possible.
- **Client Components** (`"use client"`) only for interactive UI (charts, search input).
- **Auth state** — use Supabase client session; protect routes via middleware in `middleware.ts`.
- **API calls** — always go through `apps/web/src/lib/api.ts` (Axios instance with auth header injection).
- Import path alias: `@/` maps to `apps/web/src/`.

### Both
- TypeScript strict mode on for Next.js. No `any`.
- Python type hints required on all function signatures.
- Never call Yahoo Finance directly from the frontend — always proxy through FastAPI.

## What NOT to Do

- Do **not** call Yahoo Finance or Anthropic API from `apps/web` — all external API calls go through FastAPI.
- Do **not** use the Supabase service role key on the frontend — use the anon key only.
- Do **not** commit `.env` or `.env.local` files — they are gitignored.
- Do **not** skip `Depends(get_current_user)` on protected routes.
- Do **not** use `print()` for logging — use Python's `logging` module or `structlog`.
